# 拓維空間NovaDimension

軟裝設計工作室形象網站：以 Home Planner App 為客戶量身打造房間與客廳的軟裝設計與靈感提案。

## 技術堆疊

- Next.js (App Router)
- Tailwind CSS
- Lucide React

## 開始使用

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)。

## 主要區塊

1. Navbar
2. Hero
3. Features（服務特色）
4. Process（設計流程）
5. Gallery（案例靈感）
6. CTA
7. Footer
